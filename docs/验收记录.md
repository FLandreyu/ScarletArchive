## 后端重点

- 草稿隔离：公开详情404、搜索无结果、归档与Sitemap不出现。
- 发布/取消发布：真实数据库写入后可读或变回不可读。
- 并发编辑：两个线程同时提交同一版本，只有一个保存成功，另一个收到EDIT_CONFLICT。
- 文章删除与标签关系清理、无效分类/标签回滚、有引用的分类删除约束。
- SQL注入式输入只能作为查询参数，不扩大结果；分页与排序参数校验。
- 新留言与友链默认待审核，审核后才可公开；蜜罐及登录/留言限流。
- 实际JWT签发与解码，退出提升版本号后原令牌验签链拒绝；匿名后台和上传被拒绝。
- 伪装PNG、SVG、目录穿越封面地址、javascript链接被拒绝；真实PNG解码并输出UUID命名JPEG。
- 站点设置真实持久化，未知单段前台路由交给主题页面渲染。

## 浏览器流程

1. 首页真实数据 → 搜索“事务” → 阅读页6节目录 → 语法高亮与代码复制。
2. 管理员UI登录 → 创建草稿 → 公开详情/Sitemap不可见 → 编辑发布 → 前台可读；预览和前台都不执行注入HTML。
3. 庭院留言 → 未审核不公开 → 后台审核 → 前台出现；友链申请也经过相同审核边界。
4. 标签新增/删除、站点短句修改/回读/恢复，均使用真实接口。
5. 上传项目生成PNG作为封面 → 后端重编码JPEG → 真实资源地址返回image/jpeg。
6. 公开页面、正文图片查看、7枚水晶点亮、主题404。
7. 后台退出后使用复制的旧令牌请求，服务端返回401。
8. 390px手机导航、阅读与庭院，无横向溢出，系统减少动态偏好被尊重。

测试发现并修复了水晶按钮动画造成点击目标不稳定的问题：现在按钮保持固定，只有内部晶体浮动。修正了代码高亮默认渲染器造成的嵌套pre结构，并在最终冒烟中断言不存在嵌套代码块。
