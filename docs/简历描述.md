# 项目经历参考

**Scarlet Archive 红魔馆主题个人博客**

技术栈：Java21、Spring Boot3、Spring Security、MyBatis、MySQL8、Vue3、TypeScript、Router、Pinia、Tailwind CSS、GSAP。

- 实现前后端分离个人博客，包含文章草稿与发布、Markdown安全渲染、全文关键词检索、分类标签、归档、留言及友链审核，以及可维护站长配置的管理后台。
- 使用数据库乐观版本号防止并发编辑覆盖，文章与多标签关系同事务更新；公开查询统一隔离草稿，覆盖详情、搜索、归档、计数和Sitemap。
- 基于Spring Security实现JWT认证与版本撤销，加入登录和访客提交限流；限制图片大小与像素，通过实际解码、重新编码和随机文件名处理封面上传。
- 构建主题Token与角色空间映射，使用GSAP与CSS实现不阻塞操作的动效，支持手机布局、减少动态偏好、文章TOC、阅读进度、图片查看和代码复制。
- 42项集成测试在H2和MySQL8分别通过，8条真实浏览器流程验证文章发布闭环、审核、上传、安全预览与移动端。

使用前应亲自运行并能独立讲清楚实现。项目由AI辅助开发；不要把本地演示描述为真实校园上线、生产高并发服务或正式安全审计。项目日期按自己的实际学习与维护时间填写。

讲解路线：`BlogService.save`的版本检查及条件UPDATE → 标签事务 → `SecurityConfig.decoder`的token版本校验 → `AssetService`解码重编码 → `markdown.ts`的禁用HTML和净化 → Playwright真实发布与前台读取。
