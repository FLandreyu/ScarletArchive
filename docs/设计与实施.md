# Scarlet Archive · 红魔馆手记

## 定位与实施顺序

将个人博客作为红魔馆中可阅读、探索与留言的空间。工程以模块化单体为核心，前端与REST API解耦，避免微服务和额外中间件。

1. 设计与骨架：统一主题、页面地图、数据结构和接口约定。
2. 阅读体验：首页、藏书目录、Markdown详情、搜索分类、时间归档与手机导航。
3. 真实数据：管理员认证、文章草稿与发布、分类标签、上传、审核和站点配置。
4. 特色交互：钟表转场、低成本月光、隐藏房间水晶收集、动画偏好。
5. 验证交付：后端集成测试、真实浏览器发布闭环、响应式检查、部署配置和文档。

基础版范围包含全部公开页面及真实管理后台。暂不接入LLM、评论账号系统、邮件通知、Redis、付费订阅或实时聊天室。

## 架构与目录

```text
ScarletArchive/
  backend/   Java21 / Spring Boot3 / Security / MyBatis / SQL / tests
  frontend/  Vue3 / TS / Router / Pinia / Tailwind / GSAP
  deploy/    Nginx / Dockerfiles
  docs/      设计、接口、素材来源、验收、简历描述
  scripts/   本地启动与验证
```

开发：Vite5180代理后端8098。便捷本地演示：前端构建由Spring静态资源服务同源提供，H2文件数据库开箱即用。正式部署：Nginx提供前端，`/api`与`/uploads`代理到Java后端，MySQL8持久化。H2仅为演示与快速测试替代，MySQL配置与SQL仍为交付的一部分。

## 数据库

- `admin_user`：BCrypt密码与token_version，退出令旧令牌失效。
- `category`、`tag`、`article`、`article_tag`：文章草稿/发布、置顶推荐、分类与多标签。文章乐观版本号防止覆盖其他编辑。
- `guest_message`：昵称、内容、PENDING/APPROVED，默认未审核不公开。
- `friend_link`：友链、简介、URL、PENDING/APPROVED，申请默认待审核。
- `site_config`：JSON站点信息，内容统一由后台维护。

所有列表分页，用户输入使用MyBatis参数绑定。发布查询集中限制 `status='PUBLISHED'`，单篇草稿对公开接口返回404。文章与标签关系在同一事务中更新。

## 视觉规范

午夜墨蓝底色 `#11101c`，层次暗紫 `#22172f`，绯红 `#8b1e32`，玫瑰 `#c83c5a`，古金 `#d6b47a`，暖白 `#f5edf2`，薰衣草 `#ac91c9`。Token集中在CSS，字形以衬线标题与无衬线正文区分，阅读栏最大740px。

首页主景使用原创生成的哥特红砖馆邸、月亮、湖面与玫瑰庭院；导航、书脊、星形、蝙蝠翼等使用自行绘制SVG。装饰不覆盖正文、不接收指针，不播放背景音乐。GSAP仅负责短暂首屏进场/轻微景深；CSS负责悬停和低速月光。提供独立动画开关，优先尊重系统减少动态偏好，手机不做视差。

## 安全与素材

JWT验签、到期与版本校验；退出撤销当前管理员已有令牌。登录与留言限流。Markdown关闭原始HTML并再次经过DOMPurify，链接与图片协议有限制。上传只接收JPEG/PNG位图，限制大小与像素，使用解码后重编码与随机文件名，不接收SVG和可执行内容。访客留言与申请默认待审核。

素材登记见素材说明。网站明确标注为非官方粉丝创作，与上海爱丽丝幻乐团和东方Project官方无关联。生成素材不冒充官方原画或第三方授权插画。
