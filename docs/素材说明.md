### 获取与构建

Git仓库不包含这六张PNG原文件，避免把项目变成素材的再次分发渠道。[来源清单](../frontend/character-art.json)记录作品ID、原址、尺寸和SHA-256；`frontend/scripts/fetch-character-art.mjs`在首次开发/构建时从Pixiv原址获取，校验作者、作品公开级别、免费素材说明、使用规则指纹和PNG文件哈希。

```powershell
cd frontend
npm ci
npm run assets:fetch
npm run build
```

下载后本机缓存于`frontend/public/art/characters/`，已加入Git忽略规则；浏览器访问同源图片，不需访问Pixiv，也不会向Pixiv发送访客请求。六图原始PNG合计约2.40MB，每张只在对应页面显示时加载，首屏只加载蕾米莉亚；固定尺寸避免加载后挤动布局。主站仍需具备原画使用资格，代码许可证不授予这些图片的权利。

网络需要代理时，可在本次终端设置标准`HTTPS_PROXY`环境变量；脚本不会读取浏览器Cookie或索要Pixiv账号。作者条款、图片内容或来源变化会中止首次获取，须重新核对，而不是自动替换为未知图片。

离线或不使用这套立绘时，构建前设置`SCARLET_CHARACTER_ART=off`（PowerShell：`$env:SCARLET_CHARACTER_ART='off'`），使用原有纹章与象征物设计。Docker Compose可在`.env`设置相同变量。不要把下载缓存单独打包或再上传到公开素材目录。

使用内置 `image_gen`，生成全新图片，非编辑第三方图像；原始输出已复制到项目art目录，构建时进入前端资源。未使用CLI/API密钥模式。

Create a refined original anime background painting of the Scarlet Devil Mansion from Touhou Project at a tranquil moonlit night: an elegant Victorian gothic manor of deep burgundy brick with pointed spires, warm amber lit arched stained-glass windows and a central clock tower; rose garden and wrought iron gate foreground, a distant lake and blue violet mist, a large pale ivory full moon behind the tower, fine silver stars, beautiful painterly clouds. Mansion placed in the RIGHT two thirds, LEFT third is dark atmospheric midnight indigo sky and faint tree silhouettes with ample unobstructed negative space for actual website title text. Restrained colors midnight #11101c, wine red #8b1e32, antique gold #d6b47a, dusty lavender #ac91c9. Rich detailed hand painted environmental concept art, delicate architecture, cinematic depth, peaceful and inviting, polished Japanese fantasy visual-novel background, elegant dark fantasy not horror. NO text, NO lettering, NO logos, NO interface, NO watermark, NO characters, NO blood, NO skulls. This is artwork only, not a webpage mockup.

生成图片约2.68MB，首屏只预先加载这一幅，其他封面与正文图片使用lazy loading；封面SVG通常低于2KB。后续可通过构建工具提供WebP/AVIF与srcset，当前未声称已输出这些格式。
